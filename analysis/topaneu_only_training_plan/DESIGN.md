# Design brief

## Audience and goal

面向正在实现 TopAneu Task 2 的研发人员。页面回答一个问题：严格只用 416 例 TopAneu 数据时，训练顺序、监督信号、冻结策略和进入下一阶段的条件是什么。

## Layout

单列技术报告。先给结论和数据约束，再用宽表列出阶段，随后给出五折执行节奏、准入阈值和不可学习的零样本限制。避免装饰性图表；阶段关系由表格承担。

## Visual system

- 浅色技术文档风格，高对比正文。
- 结论与红线约束使用简短 callout。
- 表格采用宽松行距，状态按“先做/后做/暂缓”区分。
- 所有数字均链接到本地诊断快照或本方案证据快照。
